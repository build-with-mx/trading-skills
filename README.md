# Trading Skills

Plugin con 9 skills de trading (oro y Nasdaq, MT5 vía Axi).

| Skill | Para qué |
|---|---|
| creador-skills-trading | Crea nuevas skills de trading |
| gestion-riesgo-avanzada | Lote, drawdown, recuperación, proyecciones |
| backtesting-estrategias | Backtests con velas reales + walk-forward |
| bot-mt5-python | Bot MT5 en Python (solo demo por defecto) |
| checklist-entrada | Puntaje 0-10 antes de cada operación |
| calendario-macro-noticias | Eventos macro en hora de Monterrey |
| psicologia-disciplina | Tilt, revancha, reglas de parada |
| revision-semanal-trading | Estadísticas y 3 acciones por semana |
| cuentas-fondeo-prop | Retos de fondeo y cómo pasarlos |

## Instalar en Claude Code
```
/plugin marketplace add build-with-mx/trading-skills
/plugin install trading-pro@trading-skills
```

Sin garantías. No es asesoría financiera.
